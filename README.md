# 家計簿(kakeibo)

毎日の支出・収入、固定費とサブスク、株と積立NISA(オルカンなど)をひとつにまとめる自分用の家計簿PWA。

- ホーム: 今月あと使える額(1日あたり)・総資産・見直しのヒント・もうすぐの支払い
- 記録: 電卓つき入力(よく使うカテゴリが前に)・レシートをAIで読む・ほかのアプリから貼り付け/CSV取り込み
- 固定費・サブスク: 登録した日に自動で記録。金額が毎回ちがうもの(水道・電気・給料)は仮の金額で入れて「確認してほしいこと」に出す
- 分析: 円グラフ・3か月平均との比較・月ごとの推移・来月の見通し・Claudeに節約を相談
- 資産: 総資産の推移、持ち株の損益(買った日の印・平均取得単価の線)、積立の口数を基準価額から自動計算、半導体指数(SOX など)と同じ日を100にして比較

## しくみ
- 無ビルド(React 18 + htm を esm.sh から)。記録は端末の IndexedDB が正本で、合言葉があれば Supabase の `kakeibo_items` と1件ずつ同期(関数 `kakeibo_api`)
- 値段とレシートは Edge Function `kakeibo`(Yahoo Finance・三菱UFJアセットマネジメントの公開データ・Gemini)
- 合言葉は じぶんノート・就活アプリと共通。合言葉入りリンクは `tools/copy-link.ps1`
- 確認用: `serve.ps1`(port 5515)で開き、`.devdata/dev.html`(見本データ・公開しない)
