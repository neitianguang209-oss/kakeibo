# 家計簿(kakeibo)

毎日の支出・収入、固定費とサブスク、株と積立NISA(オルカンなど)をひとつにまとめる自分用の家計簿PWA。

- 下のタブは 入力 / カレンダー / レポート / 資産 / その他。普段は必要な数字だけを出し、押すと奥へ進む
- 入力: 電卓つき(金額→カテゴリ→記録)。「詳しく」で写真・お店・払い方・タグ・メモ・内訳、「前から」とよく使うで数秒入力、レシートをAIで読む
- カレンダー: カレンダー / 週 / 月、さがす。記録を押すと中身(写真など)、コピー・よく使う・直す・消す
- レポート: 支出・収入・収支 → 円グラフ → カテゴリ → 記録。推移・予算・買ったもの・ヒント・見通しは1段下
- 資産: 推移 / 内訳(口座・その他の資産・タグ) / 株・投信(タグでポートフォリオ) / 配当(予想と受け取り)
- 見た目: ライト・ダーク(端末に合わせる/固定)。線画アイコン。収入=青・支出=朱

## しくみ
- 無ビルド(React 18 + htm を esm.sh から)。記録は端末の IndexedDB が正本で、合言葉があれば Supabase の `kakeibo_items` と1件ずつ同期(関数 `kakeibo_api`)
- 値段とレシートは Edge Function `kakeibo`(Yahoo Finance・三菱UFJアセットマネジメントの公開データ・Gemini)、配当は `kakeibo-div`
- `kakeibo_items` の kind は tx / rec / lot / plan / watch / conf に加えて photo(写真)・fav(よく使う)・asset(口座・その他の資産)・holding(銘柄のタグと配当)
- 合言葉は じぶんノート・就活アプリと共通。合言葉入りリンクは `tools/copy-link.ps1`
- 確認用: `serve.ps1`(port 5515)で開き、`.devdata/dev.html`(見本データ・公開しない)
